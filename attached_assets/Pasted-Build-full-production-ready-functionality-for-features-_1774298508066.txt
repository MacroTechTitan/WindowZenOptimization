==================================================

Build a smart Recommendations Engine for WindowZen that analyzes the computer state and produces useful, prioritized, non-alarmist recommendations.

Purpose:
Turn raw diagnostics into clear suggestions that help users make their Windows PC faster, leaner, less cluttered, and easier to use.

Data sources:
The engine should ingest data from existing or planned modules such as:
- startup optimizer
- storage cleaner
- app and bloat manager
- performance dashboard
- file organization tools
- brightness / wellness tools if available
- network health module if available

Recommendation categories:
- Performance
- Storage
- Startup
- Apps
- Organization
- Wellness
- Maintenance
- Network
- Accessibility / comfort

Examples of recommendation logic:
- “Your Downloads folder has 14.3 GB of old installers older than 60 days.”
- “You have 11 startup items, including 4 high-impact apps.”
- “Disk C: is below 15% free space.”
- “Desktop contains 132 files; organization is recommended.”
- “There are 27 GB of duplicate or reclaimable files.”
- “Brightness is still high during late evening hours.”
- “You have not run maintenance in 12 days.”
- “3 very large apps may be worth reviewing.”
- “Memory pressure is high with only 1.1 GB RAM available.”
- “Repeated installer downloads were detected.”

Each recommendation must include:
- title
- category
- severity or priority
- explanation in plain language
- evidence/metrics
- suggested action
- related module
- estimated benefit score
- risk level
- whether it is informational or actionable

Scoring:
Create a prioritization engine that ranks suggestions by:
- potential speed gain
- potential clutter reduction
- potential ease-of-use improvement
- urgency
- confidence
- safety

Support:
- high priority
- medium priority
- low priority
- informational only

Functionality:
- Generate recommendations from current system state
- Refresh recommendations manually or automatically
- Deduplicate similar recommendations
- Group recommendations by category
- Allow user to dismiss or snooze recommendations
- Allow recommendations to link to the relevant app module
- Store recommendation history with timestamps
- Mark which recommendations have been completed, ignored, or deferred
- Add “top 3 recommended actions” summary card

UI:
- Recommendation summary page
- Cards or list view
- Filters by category, severity, status
- “Why am I seeing this?” detail panel
- Buttons:
  - Refresh recommendations
  - Apply related action
  - Dismiss
  - Snooze
  - View evidence
  - Export recommendations report

Safety:
- Never automatically perform destructive actions
- Recommendations must be based on actual collected data
- Keep explanations transparent
- Avoid fear-based wording
- Clearly label “safe quick wins” vs “review carefully”

Deliver:
- recommendations_engine.py
- recommendation_models.py

- UI screen/component
